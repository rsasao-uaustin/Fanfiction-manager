Import from Google Docs

Paste the full URL of your Google Document. Make sure the document is shared with "Anyone with the link can view" or you're authenticated.
For private documents, you'll need a Google OAuth access token. See instructions below.

How to get an Access Token:

  1. Go to Google Cloud Console
  2. Create a project and enable Google Docs API
  3. Create OAuth 2.0 credentials
  4. Use the OAuth playground to get an access token
  5. Or use the simplified method: Share document publicly and leave token empty
